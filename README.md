# 💬 Chatroom

Многофункциональное десктопное приложение для общения, обмена файлами и ведения форума, написанное на Python с использованием библиотеки Tkinter.

## ✨ Основные возможности

*   **Чат в реальном времени**: Автообновление сообщений, поддержка собственных цветных смайликов, звуковые уведомления.
*   **Форум**: Создание категорий и страниц, обмен сообщениями, загрузка и скачивание файлов (с лимитом), редактирование и очистка постов.
*   **Профили пользователей**: Просмотр и редактирование данных (ФИО, должность, телефон), загрузка аватарок, смена паролей.
*   **Админ-панель**: Удобная таблица управления пользователями (выдача прав, удаление аккаунтов со всеми данными).
*   **Статистика**: Отслеживание объёма загруженных файлов, просмотр детального списка и удаление файлов прямо из интерфейса.
*   **Настройки**: Смена цветов ников, выбор темы оформления (Светлая, Тёмная, Синяя), настройка звуковых уведомлений.

## 🛠️ Технологии

*   **Язык**: Python 3.8+
*   **Интерфейс**: Tkinter (стандартная библиотека)
*   **База данных**: SQLite3 (локальный файл `chat.db`)
*   **Работа с изображениями**: Pillow (PIL)
*   **Сборка**: PyInstaller

## 🚀 Запуск из исходного кода

1. Убедитесь, что у вас установлен Python 3.8 или выше.
2. Установите необходимые зависимости:
   ```bash
   pip install pillow
   ```
3. Запустите приложение:
   ```bash
   python main.py
   ```
   *(При первом запуске база данных создастся автоматически, а также будет создан аккаунт администратора).*

## 📦 Сборка в EXE-файл

Для сборки проекта в один исполняемый файл используется PyInstaller. 
Поместите в корень проекта папки `ico`, `sounds` и `Smile`.

Запустите следующий PowerShell-скрипт:

```powershell
Remove-Item -Recurse -Force build, dist -ErrorAction SilentlyContinue
Remove-Item -Recurse -Force __pycache__ -ErrorAction SilentlyContinue
Remove-Item -Force main.spec -ErrorAction SilentlyContinue

pyinstaller --noconfirm --onefile --windowed --name Chatroom --icon=ico/chat.ico --add-data "ico;ico" --add-data "sounds;sounds" --add-data "Smile;Smile" main.py

Write-Host "Готово: dist\Chatroom.exe" -ForegroundColor Green
```

После завершения сборки готовый файл **`Chatroom.exe`** будет находиться в папке `dist`.

## 📂 Структура проекта

*   `main.py` — точка входа в программу.
*   `main_app.py` — главное окно приложения и навигация.
*   `database.py` — модуль для работы с базой данных SQLite.
*   `chat_panel.py` — панель чата и логика смайликов/звуков.
*   `forum_view.py` — панель форума.
*   `admin_users_view.py` — панель администратора.
*   `settings_view.py` — панель настроек.
*   `statistics_view.py` — панель статистики.
*   `profile_view.py`, `profile_edit.py` — окна просмотра и редактирования профиля.
*   `users_list.py` — виджет списка пользователей.
*   `utils.py` — вспомогательные функции (темы, работа с файлами и т.д.).
*   `ico/` — иконки приложения и интерфейса.
*   `sounds/` — звуковые файлы (`.wav`) для уведомлений.
*   `Smile/` — папка со смайликами (PNG-файлы).
